# План релізу v1.0.0 — CarRental Project

## 1. Що входить у версію v1.0.0
* Повний життєвий цикл замовлення (Створення, Розрахунок зі стратегіями, Завершення, Нарахування штрафів).
* Стійке збереження даних у поліморфний `JsonDataStore`.
* Повний набір автоматизованих тестів (20 юніт-тестів та 8 інтеграційних тестів).
* Інтерактивне консольне UI меню для користувача.

## 2. Технічний борг та плани "після курсу"
* Перенесення локального JSON-сховища на повноцінну реляційну БД (PostgreSQL).
* Розробка графічного Web-інтерфейсу (Blazor/React) замість поточного консольного меню.

## 3. Матриця покриття базових тем
* **SOLID:** Принцип єдиної відповідальності (SRP) впроваджено через розділення сховища даних та бізнес-сервісів; DIP реалізовано через інтерфейси.
* **Патерни:** Патерн `Strategy` для гнучкого розрахунку вартості оренди залежно від тривалості та днів тижня.
