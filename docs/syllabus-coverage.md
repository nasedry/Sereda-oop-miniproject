# Матриця покриття тем курсу (Syllabus Coverage)

| Група тем курсу | Що використано обов'язково у проєкті | Розширення / Особливості реалізації |
| :--- | :--- | :--- |
| **Основи ООП** | Класи `Vehicle`, `Order`, `Customer`. Інкапсуляція станів та приватні сетери. | Обмеження на зміну статусу замовлення ззовні доменних моделей. |
| **Абстракції, поліморфізм** | Базовий абстрактний клас `Vehicle` та його спадкоємці (`PassengerCar`). | Поліморфна обробка списку машин під час виведення в консоль. |
| **Generics, Колекції, LINQ** | `IEnumerable<T>`, generic-клас `JsonDataStore<T>` для повторного використання коду. | Складні аналітичні LINQ-запити для фільтрації доступних авто. |
| **Обробка помилок & Persistence** | Контроль введення-виведення (I/O), обробка пошкоджених файлів. | Використання патерну `Result` для безпечного повернення помилок. |
| **SOLID принципи** | Розділення інтерфейсів (ISP), інверсія залежностей (DIP) через конструктори. | Код повністю позбавлений жорстких статичних зв'язків. |
| **Патерни проектування** | Патерн `Strategy` для гнучкої тарифікації оренди. | Реалізовано `LongTermRentStrategy` та `WeekendStrategy`. |
| **Тестування & Рефакторинг** | Тестова піраміда: 20 Unit-тестів, 8 Integration-тестів, збір Coverage. | Використання `coverlet` та ізоляція тестів через тимчасові файли. |
