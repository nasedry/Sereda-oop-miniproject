# Інструкція з запуску тестів

## Як запустити тести локально
1. Відкрийте термінал в корені проєкту `D:/CarRentalProject`.
2. Виконайте команду для запуску всього тестового люксу:
   dotnet test
3. Для запуску з генерацією метрик покриття (Code Coverage) виконайте:

   dotnet test /p:CollectCoverage=true /p:CoverletOutputFormat=opencover
## Опис тестового покриття:
1. Юніт-тести (20 тест-кейсів): Покривають критичну доменну логіку, обмеження на кількість місць, інваріанти періодів оренди, патерни розрахунку знижок і штрафів за протермінування, а також аналітичні LINQ-запити.   
2. Інтеграційні тести (8 тест-кейсів): Перевіряють збереження стану на диск у JSON, поліморфне завантаження, стійкість до пошкодженої структури файлу (IT_6) та автоматичне відновлення порожньої колекції у разі відсутності файлу (IT_7).
