# Система прокату автомобілів (CarRental System) v1.0.0

Програмний комплекс для автоматизації процесів оренди автомобілів, розроблений у рамках навчальної практики з об'єктно-орієнтованого програмування.

## Основний функціонал програми
* Перегляд повного каталогу автомобілів, їхніх держномерів та вартості оренди за добу.
* Покрокове оформлення прокату автомобіля клієнтом із перевіркою посвідчення водія.
* Автоматичний розрахунок вартості оренди з урахуванням тривалості замовлення та вихідних днів.
* Фіналізація замовлень, повернення автомобіля в автопарк та автоматичний підрахунок штрафів за затримку.
* Захист системи від повторного бронювання вже зайнятої машини.
* Збереження всіх внесених даних та історії замовлень у локальні файли JSON.

## Навігація по меню програми для користувача
При запуску програми відкривається текстове інтерактивне меню. Керування здійснюється за допомогою введення відповідної цифри в консоль:
1. Вибір пункту "Перегляд каталогу" виводить на екран список усіх машин та їхній поточний статус (доступна в автопарку чи наразі орендована).
2. Вибір пункту "Оформити прокат" запускає покроковий майстер створення замовлення, де потрібно послідовно ввести ім'я клієнта, номер ліцензії, обрати авто та вказати кількість днів оренди.
3. Вибір пункту "Повернути автомобіль" закриває активне замовлення, повертає машину в каталог доступних та виводить фінальний чек із розрахунком вартості.
4. Вибір пункту "Вихід" примусово зберігає всі поточні зміни на диск та завершує роботу додатка.
