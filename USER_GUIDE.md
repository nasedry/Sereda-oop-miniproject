# Посібник користувача (User Guide) — CarRental System

## Як користуватися програмою (Консольне меню)
При старті застосунку перед вами з'явиться головне меню. Вводьте номери пунктів для навігації:

1. **Переглянути доступні авто:** Виводить список усіх машин у системі з їхніми характеристиками (марка, кількість місць, базовий тариф).
2. **Створити нове замовлення:** Програма попросить ввести ID клієнта, ID автомобіля та кількість днів оренди. Система автоматично розрахує вартість з урахуванням знижок.
3. **Завершити оренду:** Виберіть активне замовлення для повернення авто. Якщо є протермінування, система автоматично нарахує штраф.
4. **Вихід:** Безпечне збереження всіх змін на диск у JSON-базу та закриття програми.
